The Post-Production Rush: Behind the Screen
An interactive educational game that simulates the high-pressure world of media post-production. Navigate through the studio, manage your time, and guide a digital project through all 6 essential phases of post-production—from raw data ingestion to the final master delivery.

🌟 Features
6 Production Stages: Ingestion, Editing, Sound Mix, Color Grade, VFX & Graphics, and Mastering.

Interactive Mechanics:

Collect coffee mugs ☕ for energy boosts and time reductions (-3s).

Dodge the persistent client who shows up with last-minute revisions (+10s penalty)!

Built with Python & Pygame: A lightweight, retro-inspired pixel-art visual style.

Credits: Developed by Alessandra Zapata.

🚀 How to Run
Prerequisites: Make sure you have Python installed on your computer.

Install Pygame: Open your terminal or command prompt and run:

Bash
pip install pygame
Launch the Game: Navigate to the game folder in your terminal and run:

Bash
python main.py
🎮 Controls
Movement: Arrow Keys or W, A, S, D

Restart / Replay: Press [R] on the victory screen when you finish the game!
